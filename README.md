# analyser-for-files-

AI-powered folder organization tool with a Tkinter GUI. Scans a directory tree, builds a file inventory, calls an LLM (ApiFreeLLM) for reorganization suggestions, and lets you preview + approve moves via CLI or GUI. Includes rollback manifest.
